# ToolVerse Backlink Playbook (White-Hat Only)

> **Asaan plan (2025–2026):** start with [`seo/easy-backlinks-guide.md`](./easy-backlinks-guide.md) — prioritized places, click steps, copy-paste drafts, weekly 3-actions/day. Yeh file = longer templates + checklist.

Site: [https://toolverse.baby](https://toolverse.baby) · Pitch: **~95 free online tools, no signup, privacy-first (browser-side), Pakistan salary tax + Zakat niche**

**Hard no:** PBNs, bought links, link farms, fake reviews, cloaking, comment spam, mass guest-post networks.

---

## 1. Strategy (plain language / Hinglish OK)

Backlinks = doosri websites se ToolVerse pe link. Google trust yahan se aata hai.

**Hamara method (3 layers):**

1. **Earn listings** — free directories / software lists pe ToolVerse (ya single strong tools) submit karo. Account USER banata hai; AI listing copy + screenshots checklist deta hai.
2. **Earn mentions** — useful content (blog pillars, comparison guides, Pakistan tax guide) jo log naturally link karein. AI drafts; USER share / outreach karta hai.
3. **Ask politely** — resource pages, guest posts, “tools we use” lists pe short email. Templates below. USER inbox / replies handle karta hai.

**Unique angles jo pitch mein hamesha lagao:**
- Files process **100% in-browser** (PDF/images nahi upload)
- **Free + no signup**
- Pakistan niche: **Salary Tax Estimator** + **Zakat Calculator**
- Job applicants: compress photo to **20KB / 50KB** for portals
- Bundle: image, PDF, QR/barcode, JSON, calculators, writing tools — one place

**AlternativeTo tip:** Poora “tool directory” reject ho sakta hai. Prefer **individual tools** submit karo (e.g. PDF Merge, Image Compressor, Password Generator) as alternatives to ILovePDF / TinyPNG / etc.
